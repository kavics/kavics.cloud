# 101 Content query

Query without field searches the `_Text` field 

| CQL&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | Note |
|:------- |:------ |
| Jupiter | Contains the "Jupiter". |
| Jupiter Saturn | Contains any of the "Jupiter" or "Saturn". |
| +Jupiter +Saturn | Contains both "Jupiter" and "Saturn". |
| Jupiter Saturn -Neptun | Contains any of the "Jupiter" or "Saturn" but not contains "Neptun". |
| +Jupiter Saturn | The "Saturn" is irrelevant clause because if a document contains the "Jupiter" it is a hit and it does not depends on whether the "Saturn" is present. |

## Fields
Field names are always case sensitive but values are never. The following queries are the same:
- Name:saturn
- Name:SaTUrn

Value should be enveloped by pairs of quotation marks or aposthrophes if the value contains any of the string terminator characters: **" : + - & | ! ( ) { } [ ] ^ ~**

Name:'Saturn'
Name:"Saturn"
Name:Saturn-ring --> Name:saturn -ring --> Name:saturn _Text:-ring

## Common search-related metafields
These read-only fields are only for the search, they do not store data. 

| Field | Description | Example |
|:-|:-|:-|
| InTree | Returns the given folder and all contents under it | InTree:"/Root/MyContent" |
InFolder | Returns all content in that particular folder | InFolder:"/Root/MyContent/Media" |
| Type | Returns all content that is of the given type | Type:Article |
| TypeIs | Returns all content that is of the given type or any subtype | TypeIs:WebContent |

## DateTime
- **CQL**: `ModificationDate:<'2345-06-07 08:09:10.0000'`
- **SnLinq**: `Content.All.Where(c => c.ModificationDate < DateTime.UtcNow.AddDays(-2));`

## Empty string
- **CQL**: `DisplayName:''`
- **SnLinq**: `Content.All.Where(c => c.DisplayName == "");`

## Null string
- **CQL**: `DisplayName:''`
- **SnLinq**: `Content.All.Where(c => (string)c["DisplayName"] == null);`

## Single negative term
It is forbidden to use a single negative expression, but you can use an irrelevant positive expression as a complement. SnLinq automates this.
- **CQL**: `-Id:42` is forbidden but it works: `-Id:42 +Id:>0`
- **SnLinq**: `Content.All.Where(c => c.Id != 42);`

## OfType&lt;T&gt;() in SnLinq
The basic queryable object provides the `Content` itemType.
The `OfType` filters the defined ContentType family and provides the type-correct ContentHandler
- Content.All.Where(c -> ... *c is Content*
- Content.All.**OfType&lt;Memo&gt;()**.Where(m -> ... *m is Memo content handler*

## Single-reference
The `mother` is a ContentHandler instance.
- **CQL**: `$"Mother:{mother.Id}"`
- **SnLinq**: `Content.All.OfType<RefTestNode>().Where(c => c.Mother == mother);`

## Multi-reference query:
The field type must be IEnumerable&lt;Node&gt;. IEnumerable&lt;RefTestNode&gt;, IEnumerable&lt;Place&gt; does not work)
- **CQL**: `$"Neighbors:{node.Id}"`
- **SnLinq1**: `Content.All.Where(c => ((RefTestNode) c.ContentHandler).Neighbors.Contains(node))));`
- **SnLinq2**: `Content.All.OfType<Place>.Where(c => c.AcceptedBicycleTypes.Contains(bicycleType));`

## Any reference
Works with single and multireference fields too.
- **CQL**: `+Type:Bicycle +Place:>0`

## Null reference
Works with single and multireference fields too.
- **CQL**: `+Type:Bicycle -Place:>0`

## Templates

+ModifiedBy:@@CurrentUser@@

These are the built-in parameters that you can use in your queries:

Parameter | Note
:----------|:------
CurrentUser | Represents the currently logged in user
CurrentDate | Current date, meaning the very start of the day, e.g.:9/17/2010 00:00:00
CurrentTime | Current time, e.g.:10/23/2010 14:30:00
CurrentMonth | Current month
CurrentContent | Current content
CurrentWorkspace | Current workspace
CurrentSite | Current site
Today | Equivalent to CurrentDate and CurrentDay: represents the start of the current day (00:00 AM).
Yesterday | Start of the previous day.
Tomorrow | Start of the next day.
CurrentWeek | Start of the current week. This builds on the first weekday defined by the current culture (which is Sunday in some cultures, Monday in others).
CurrentMonth | Start of the current month.
CurrentYear | Start of the current year.
NextWorkday | Start of the next workday. It skips weekends but it does not know anything about holidays.
NextWeek | Start of the next week. This builds on the first weekday defined by the current culture.
NextMonth | Start of the next month.
NextYear | Start of the next year.
PreviousWorkday | Start of the previous workday. It skips weekends but it does not know anything about holidays.
PreviousWeek | Start of the previous week. This builds on the first weekday defined by the current culture.
PreviousMonth | Start of the previous month.
PreviousYear | Start of the previous year.

## Get CQL from SnLinq:
Original query:
```csharp
var memos = Content.All.DisableAutofilters()
    .Where(c => c.TypeIs(nameof(Memo)))
    .ToArray();
```
Rewritten query and CQL text extraction
```csharp
var memosQueryable = Content.All.DisableAutofilters()
    .Where(c => c.TypeIs(nameof(Memo)));
var contentSet = memosQueryable.Provider as ContentSet<Content>;
var cqlText = contentSet?.GetCompiledQuery().ToString();
var memosArray = memosQueryable.ToArray();
```
